# Peluches Patty · demo

Prototipo de tienda de peluches con tres flujos: catálogo (menor y mayor), pedido con QR de retiro y panel de despacho con lector de QR.

- Datos de ejemplo, sin pagos reales ni servidor: todo se guarda en el navegador (`localStorage`).
- El QR del cliente lleva el pedido completo, así que el despachador puede leerlo desde otro dispositivo sin backend.
- Fotos de ejemplo: [Pexels](https://www.pexels.com) (licencia libre).
- Un solo archivo: `index.html`.
